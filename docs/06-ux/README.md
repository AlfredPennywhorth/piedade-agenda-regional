# UX / Interface

Este diretório contém a documentação de UX e design do projeto **Agenda Regional São Paulo**.

## Princípios de design

- **Acessibilidade**: WCAG 2.1 AA mínimo
- **Mobile-first**: maioria dos usuários acessa via celular
- **PWA**: instalável, funciona offline (parcialmente)
- **Clareza**: interface para usuários não-técnicos

## Tipografia

- **Família**: Inter (Google Fonts)
- **Pesos**: 400 (regular), 500 (medium), 600 (semibold), 700 (bold)

## Fluxos previstos (a detalhar pelo PMO)

- Ativação de conta via link individual
- Validação de identidade (celular + data de nascimento)
- Acesso à agenda de reuniões
- Confirmação de presença em convocação
- Consulta de histórico
