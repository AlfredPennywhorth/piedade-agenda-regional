# Capturas reais — Manual de Uso (issue #170)

Este diretório guarda **somente imagens reais da Agenda Regional homologada**, organizadas por jornada. Imagens do Google Stitch são referências de design e **não** são capturas da aplicação.

## Procedimento de coleta
1. Acesse a versão de **Beta homologada** e registre no controle editorial o ambiente, versão/build, data, tela/código AGD, perfil de teste e viewport (desktop/mobile).
2. Utilize conta de teste e dados fictícios. Antes de incluir arquivos, oculte por completo nomes reais, celulares, carteirinhas, links de ativação, PINs, tokens, identificadores privados e outros dados pessoais. Evite salvar a versão sem anonimização no repositório.
3. Salve PNG ou WebP com nomes minúsculos e descritivos, por exemplo `agd-adm-007-setores-lista-mobile.webp`; não use capturas do Stitch nem screenshots de versões não homologadas como se fossem definitivas.
4. Adicione a imagem na subpasta correspondente e faça referência relativa no capítulo Markdown: `![Lista de Setores no celular](imagens-manual/estrutura-territorial/agd-adm-007-setores-lista-mobile.webp)`.
5. Revise legibilidade, texto alternativo, ausência de dados sensíveis, correspondência com a versão documentada e aprovação editorial do PO.
