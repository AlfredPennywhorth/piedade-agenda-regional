# Governança

Este diretório contém os documentos de governança do projeto **Agenda Regional São Paulo**.

## Conteúdo esperado

- Estrutura organizacional e hierarquia institucional
- Papéis e responsabilidades (PMO, Lead Dev, QA, etc.)
- Processo de aprovação de mudanças de escopo
- Política de comunicação entre equipes
- Processo de gestão de riscos
- Critérios de aceite de sprints

## Regras de governança (resumo)

- Decisões de arquitetura funcional, escopo e regras de negócio **requerem aprovação do PMO**
- Decisões técnicas internas à stack aprovada podem ser tomadas pelo Lead Dev com registro em ADR
- Modificações na stack aprovada requerem aprovação do PMO
