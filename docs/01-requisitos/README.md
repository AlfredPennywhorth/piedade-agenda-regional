## Premissas conhecidas (Sprint S00)

- Mais de 500 usuários finais previstos
- Custo operacional inicial: R$ 0
- Sem dependência de SMS ou e-mail obrigatório para acesso
- Autenticação própria no backend (ver ADR-001)
- Dados pessoais tratados conforme LGPD (ver /04-seguranca-lgpd)
