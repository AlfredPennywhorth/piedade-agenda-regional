# Decisões Arquiteturais (ADR)

Este diretório contém os registros de decisões arquiteturais (Architecture Decision Records) do projeto **Agenda Regional São Paulo**.

## Formato

Cada ADR segue o formato:
- **Status**: RASCUNHO | DECIDIDO | SUBSTITUÍDO | OBSOLETO
- **Contexto**: Por que a decisão foi necessária
- **Opções avaliadas**
- **Decisão**: O que foi decidido e por quem
- **Consequências**: Impactos da decisão
