## Regras de utilização

- Os HTMLs são referências de design, não componentes executáveis do sistema.
- Preservar os arquivos originais para rastreabilidade.
- Os dados fictícios apresentados pelo Stitch não devem ser incorporados ao sistema.
- Rótulos, títulos, legendas, campos, filtros e funcionalidades devem respeitar a aplicação existente.
- Preservar as regras de negócio, os perfis de acesso e as permissões vigentes.
- A implementação deverá utilizar os componentes React/Tailwind existentes e os tokens compartilhados de tema claro e escuro.
- Não copiar diretamente os scripts demonstrativos do Stitch para a aplicação.
- Exibir versão, build e ambiente dinamicamente, somente no rodapé.
