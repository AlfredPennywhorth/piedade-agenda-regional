# Protótipos Stitch — Setores

Os quatro HTMLs da pasta `setores/` foram **renomeados sem alterar nenhum byte**, conforme os códigos identificados nos próprios arquivos.

- `AGD-ADM-007-desktop.html`: listagem desktop.
- `AGD-ADM-007-mobile.html`: listagem mobile.
- `AGD-ADM-041-cadastro.html`: cadastro.
- `AGD-ADM-042-edicao.html`: edição com formulário completo.

**Não publicar** o arquivo em `nao-publicar/`: é uma variante defeituosa da tela 042, com blocos repetidos de filtros e sem o formulário de edição. Foi preservada apenas para comparação e rastreabilidade.

Ressalvas: textos, nomes de usuário, versões e totais exibidos nos protótipos são demonstrativos, não fonte de dados do sistema. O cabeçalho e o logotipo devem seguir o padrão institucional aprovado; versão, build e ambiente somente no rodapé dinâmico da aplicação. A identidade cromática escura e a compatibilidade com a diretriz de tema devem ser validadas pelo PO.

Este pacote **não altera o GitHub** e não concede aprovação de implementação, merge ou deploy. Usar nova branch baseada em `develop`.
